# Атлас будущего 2.0 — лаборатория научной фантастики

Одностраничная офлайн-дружественная PWA. Без сервера и нейросети.

## Установка на GitHub Pages

1. Создайте отдельный репозиторий или используйте существующий для «Атласа будущего».
2. Распакуйте ZIP-архив и **загрузите именно файлы из него** в корень репозитория (`index.html`, `manifest.webmanifest`, `sw.js`, иконки и этот README).
3. В Settings → Pages выберите Deploy from a branch → `main` → `/ (root)`.
4. Откройте опубликованную ссылку в Safari/Chrome. Встроенный просмотрщик ChatGPT часто не запускает JavaScript.
5. При обновлении сайта замените все старые файлы; новая версия service worker обновит кэш при следующем открытии.

## Новое в 2.0

- **Что, если…** — 36 тщательно составленных концепций в 9 направлениях, с научным допущением, последствиями, моральной дилеммой, поворотом, сценой и вопросом для проверки. Можно редактировать несколько вариантов, добавлять выбранный в сюжетные линии.
- **Цивилизации** — 8 различных согласованных типов среды и биологии: океаническая, роевой разум, машинная, симбиотическая, подземная, атмосферная, постчеловеческая и планетарная сеть. Анкеты можно свободно править, записывать в библию мира; изменения в конструкторе синхронизируются с перенесённой записью.
- Всё сохраняется **внутри того же проекта**, входит в JSON-экспорт, Markdown рукописи и архив избранного. Совместимо с JSON «Атласа будущего 1.0».

## Сохранение и осторожность

Данные хранятся в localStorage **по адресу сайта и профилю браузера**, а не в репозитории GitHub. Периодически выбирайте «Книга» → «Проект · JSON» и храните копию отдельно. Переименование адреса сайта или очистка данных браузера может сделать локальные проекты недоступными. Перед обновлением сделайте резервную копию.

Генератор работает локально, **не является научной проверкой достоверности**; обосновывайте собственные допущения и ограничения в разделе «Научная модель».
